# OpenLUPAS

> Know What Matters.

OpenLUPAS is a public education and knowledge platform.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js (App Router)
- TypeScript (Strict Mode)
- Tailwind CSS
- ESLint
